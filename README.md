BugBoard26 🚀

Sistema Cloud-Native di Bug Tracking con interfaccia Kanban.

BugBoard26 è un'applicazione web progettata per gestire il workflow delle segnalazioni tecniche. Il progetto punta sulla separazione tra logica di business e interfaccia, sfruttando la scalabilità dei servizi AWS.

🛠️ Tech Stack & Skills
Backend (Java & Spring Boot): Sviluppo di API RESTful, gestione della persistenza con JPA/Hibernate e logica di accesso basata sui ruoli.

Frontend (JavaScript, HTML5, CSS3): Manipolazione dinamica del DOM (Vanilla JS), gestione asincrona con Fetch API e design responsivo tramite Flexbox.

Cloud & Database (AWS & MySQL): Hosting del frontend su Amazon S3, gestione database relazionale su Amazon RDS (conformità ACID) e modellazione in 3NF.

✨ Funzionalità Principali
Kanban Board: Visualizzazione dinamica dei ticket (Open, In Progress, Done).

Filtri Intelligenti: Ricerca e filtraggio in-memory per ridurre la latenza e il carico sul server.

Multimedia: Gestione degli allegati tramite conversione Base64.

Collaborazione: Sistema di commenti real-time integrato per ogni issue.

🏗️ Architettura
L'app segue un modello Cloud-Native:

Frontend: Static Hosting su Amazon S3.

Backend: Server Java Spring Boot.

Database: MySQL su Amazon RDS protetto da Security Groups.
